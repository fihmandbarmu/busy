# Modern Business Web App A lightweight, responsive frontend web application designed for a small business or agency. ## Features * **Responsive Design:** Looks great on desktop and mobile. * **Dynamic Services:** The services section is populated using JavaScript, making it easy to update your offerings without touching the HTML. * **Interactive Contact Form:** Captures user input and triggers a JavaScript alert (ready to be connected to a backend). ## How to Run 1. Ensure all four files (`index.html`, `style.css`, `script.js`, `README.md`) are saved in the same directory. 2. Double-click `index.html` to open it in your default web browser. 3. No server setup is required for this basic frontend!
